# Smart Trolley Installation Map

Canonical installation path on the Raspberry Pi:

- `/home/josemsotov/robot_ws`

Important runtime files:

- ROS2 workspace source: `/home/josemsotov/robot_ws/src`
- Runtime configuration: `/home/josemsotov/robot_ws/config/robot_follower.env`
- Startup scripts: `/home/josemsotov/robot_ws/scripts`
- User services:
  - `/home/josemsotov/.config/systemd/user/robot-follower.service`
  - `/home/josemsotov/.config/systemd/user/robot-operator-web.service`

Enabled services:

- `robot-follower.service`: launches Arduino bridge, LiDAR, Kinect, gesture node, follower.
- `robot-operator-web.service`: web operator UI on port 8080.

Backup location on the Pi:

- `/home/josemsotov/SMART_TROLLEY_INSTALLATION/backups`

Use this command on the Pi to create a fresh backup:

```bash
/home/josemsotov/SMART_TROLLEY_INSTALLATION/scripts/backup_smart_trolley_pi.sh
```

The backup intentionally excludes `build/`, `install/`, and `log/` because they are generated by `colcon build` and runtime execution.
